1. SLA Resin 3D Printing & Chemical Post-Curing

Stereolithography (SLA) additive manufacturing uses UV light to selectively polymerize liquid photopolymer resin layer-by-layer. Translucent green resin was selected to verify intricate mechanical features and smooth surface finishing.

2. Fusion 360 Parametric CAD & Laser Cutting Kerf Test

2.1 Parametric CAD Design in Autodesk Fusion 360

To create interlocking press-fit joints that adjust automatically to different sheet thicknesses and laser kerf variations, we set up a fully parametric sketch in Autodesk Fusion 360 using User Parameters instead of hardcoded values.

Fusion 360 User Parameters Table

Parameter Name Expression / Value Description
material_thickness 3.00 mm Measured nominal thickness of stock sheet material
laser_kerf 0.18 mm Experimental laser beam burn-off width
pressfit_clearance 0.05 mm Tightness offset (+0.05 tight, -0.05 loose fit)
slot_width material_thickness - laser_kerf - pressfit_clearance Calculated slot width equation = 2.77 mm

2.2 CO2 Laser Cutting & Kerf Measurement Methodology

The CO2 laser cuts by vaporizing material along the vector trajectory. The width of this removed line is the Kerf. We conducted a multi-slot comb test across 3.0 mm MDF and Acrylic to determine the exact laser kerf and verify press-fit tolerances using digital vernier calipers.

Kerf = ( Total Theoretical Slot Gap - Total Measured Stack Width ) / N Cuts
