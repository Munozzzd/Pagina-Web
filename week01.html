Challenges Encountered & Problem Solving

  • Git folder structure limitation: Git cannot track empty directories. To create the media repository (img/) directly on GitHub, dummy placeholder commits (.gitkeep) were created before bulk uploading binary assets.
  • Asset naming and Unix case-sensitivity: Image paths failed during initial browser caching due to case sensitivity differences between local Windows environments and GitHub Pages Unix web servers (e.g., ABOUTAS.jpeg vs aboutas.jpeg). Resolved by standardizing file naming conventions across the repository.
  • Aggressive browser caching: Changes to CSS layouts and newly pushed images did not reflect immediately due to CDN caching. Hard refresh bypasses (Ctrl + F5) and monitoring the GitHub Actions build queue confirmed real-time deployment status.

2. Project Presentation & AI-Assisted Concept Prototyping

Kurimanya Kids Concept Vision

Conventional clubfoot orthoses (AFO and abduction braces) present high abandonment rates in developing countries due to excessive acquisition costs ($250–$400 USD), rapid sizing obsolescence, and absence of adherence data. Our project proposes a smart, modular, open-source pediatric orthosis locally manufactured via digital fabrication tools (3D printing in PETG/TPU, laser cutting, and embedded electronics) at FabLab Cuenca.

Conceptual Prototype 1: Modular Growth Architecture

Modular sizing progression demonstrating how the embedded sensor core and mechanical hinges transfer across newly printed structural shells as the child develops, reducing replacement cost to ~$8–$12 USD.

Conceptual Prototype 2: Visual Biofeedback & Telemetry

Integration of plantar force sensors in the heel with interactive LED biofeedback, stimulating proper gait contact while broadcasting pressure distribution maps to a clinical tablet interface.
